# Digital-Nixie-Tube
This is a RGB clock that mimics a Nixie Tube clock
## PCB
I used Kicad to design my pcb and schematic
<img width="1917" height="982" alt="Screenshot 2026-11-11 181757" src="https://github.com/user-attachments/assets/d2bc6204-b3e5-4533-95f9-5d7e5082d646" />
<img width="1250" height="847" alt="Screenshot 2026-11-11 181805" src="https://github.com/user-attachments/assets/706049ba-b907-44a4-9cf1-2722205bda54" />
It is a 150 x 275 mm board that is a multi sided polygon. 
## Components
I added 40 SK6812MINI-Es and 6 Cherry MXs. I am using the ESP32-C3-DevKitM-1 for the micro controller.
